# 🛡️ Cyber Incident Reporting System

A web-based **Cyber Incident Reporting System** designed to help users report, manage, and track cybersecurity incidents through a structured and centralized platform.

## 📌 Overview

The Cyber Incident Reporting System provides a simple interface for reporting cyber incidents such as:

* Phishing and suspicious emails
* Online fraud
* Unauthorized account access
* Data breaches
* Malware incidents
* Identity theft
* Cyberbullying
* Suspicious online activities

The system helps organize incident information and makes it easier for authorized users to review and manage reports.

## 🚀 Features

* 📝 Submit cyber incident reports
* 📋 View and manage reported incidents
* 🔍 Search and filter incidents
* 📊 Incident status tracking
* 🔐 Secure handling of incident information
* 👤 User-friendly reporting interface
* 📈 Dashboard for incident monitoring
* 🗂️ Centralized incident records

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js / Express.js
* **Database:** MongoDB

## 📊 Incident Status

A reported incident can have different statuses:

* **Submitted** – Report has been received
* **Under Review** – Report is being examined
* **In Progress** – Investigation/action is ongoing
* **Resolved** – Appropriate action has been completed
* **Closed** – Incident has been finalized
